# Official logo files

Only official Blockchain at Berkeley files go here. Never redraw a logo in code, and don't add Ripple or XRPL logos: the app names the network and asset in text. The app looks for each name as `.svg` first, then `.png`, and shows the org name as text if neither exists.

- `bab-logo`, `bab-logo-on-dark`: the Blockchain at Berkeley logo, for light and dark surfaces
- `bab-mark.png` (gold), `bab-mark-on-dark.png` (white): the B@B mark alone, on claim cards
