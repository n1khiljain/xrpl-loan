# Official logo files

From the B@B design team's "B@B x Frax College Screens" canvas. Only official files from Blockchain at Berkeley and Frax go here. Never redraw a logo in code. The app looks for each name as `.svg` first, then `.png`, and shows the org name as text if neither exists.

- `bab-logo`, `bab-logo-on-dark`: the Blockchain at Berkeley logo, for light and dark surfaces
- `frax-logo`, `frax-logo-on-dark`: the Frax wordmark
- `bab-mark.png` (gold), `bab-mark-on-dark.png` (white): the B@B mark alone, on claim cards and as the Safe App icon
- `frxusd-mark.png`, `frxusd-mark-on-dark.png`: the frxUSD coin
- `frax-3d.png`, `frxusd-3d.png`: Frax's 3D token renders from https://frax.com/brand ("Token & product marks"), downloaded unchanged, used on two landing feature cards
