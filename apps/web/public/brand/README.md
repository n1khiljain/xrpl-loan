# Logo

The product is Install. Its logo is a mark (an arrow coming down onto a base line, drawn on a 5x5 grid of the identity's glyphs, with the landing point in spot orange) beside the name set in the display font.

The app draws the logo in code (`components/brand/lockup-view.tsx`); these PNGs are exports of it for use outside the app. All are transparent.

| File | Use |
|---|---|
| `install-lockup.png` | Mark and name, Night, on light backgrounds |
| `install-lockup-white.png` | Mark and name, white, on dark backgrounds |
| `install-mark.png` | Mark alone, Night |
| `install-mark-white.png` | Mark alone, white |

The `bab-*` files are older files kept for the brand folder lookup; the app does not draw them.
